# 曹操传加速补丁：6.5 / 6.6

本项目保存曹操传加速补丁源码，以及既有 6.6 单文件安装器。源码包含阶段加速、超级加速、齿轮模块、简易攻略、战斗统计、存档统计持久化、安装与卸载逻辑及对应离线测试。

## 当前源码与已有发布包

- [`source/`](source/)：`1.1.0` **战场统计修复候选源码**，支持标准 6.5 基底和通过布局校验的 6.6 / 6.6x 变体。6.5p / 6.5pl 不在本次兼容承诺内。
- [`source/双版本开发说明.md`](source/双版本开发说明.md)：双版本结构、私有数据目录、存档扩展、安装事务及尚待完成的实机验收。
- [`release/加速补丁6.6安装器.exe`](release/加速补丁6.6安装器.exe)：仓库原有 `6.6.11` 安装器，面向 6.6。它与当前 `1.1.0` 候选源码属于不同构建，不能据此安装器判断双版本候选的行为。
- 平台：Windows x86；构建工具：Visual Studio 2022 Community x86 C++ 工具链及 Windows SDK；使用 C++17 和静态 CRT。

`1.1.0` 候选实现了按引擎布局选择的双载荷、战场和全局两个统计账本、E5S 内嵌统计块、原生保存事务及场景生命周期识别。安装、升级与卸载分别管理 `patch\xiaoan65` 和 `patch\xiaoan66` 的私有数据，并保留首次安装备份。

## 构建

在 `source` 目录打开 Windows PowerShell 5.1 或 PowerShell 7，执行：

```powershell
.\build-dual.ps1 -Tests
```

脚本通过 Visual Studio 2022 Community 的 `vcvars32.bat` 初始化 x86 工具链。`build.cmd` 执行普通构建，`build-tests.cmd` 构建两版载荷及测试程序。`build\common` 保存公共齿轮与卸载助手，`build\65` 和 `build\66` 保存各版 DLL 及测试，`build\package` 保存候选安装器 `加速补丁安装器.exe`。

`-Publish` 会复制安装器到开发目录外的发布路径，源码归档和离线验证时无需使用；候选版本须先完成下述实机验收再发布。

## 离线验证

回归测试需要本地持有的两套游戏基底。仓库不分发游戏本体、剧本、数据文件或测试游戏副本。先完成上述 `-Tests` 构建，再在 `source` 目录显式指定两套基底及隔离输出目录：

```powershell
.\verify-dual.ps1 `
    -GameRoot65 'D:\CCZ\加强版6.5未加密版' `
    -GameRoot66 'D:\CCZ\复刻版6.6山贼 国庆' `
    -OutputDirectory '.\build\verification'
```

两套基底需要相应的 `Ekd5.exe`、游戏数据与测试剧本；6.5 基底还需原始 `Koeicda_org.dll`，6.6 基底还需 `ExtendData.dll`。脚本只读取基底；安装事务与故障回滚测试在隔离目录内执行。日志及 `results.json` 写入指定输出目录，测试程序和构建产物不属于发布内容。

原生扩展存档校验需要 6.6 基底 `SV` 目录中至少七个 `.EXS` 样本，并逐一校验目录中所有样本；存在额外存档时继续覆盖这些样本。

`-GameRoot65`、`-GameRoot66` 均可省略。省略时保留原开发目录约定：从 `source` 向上四层寻找 `基底\加强版6.5未加密版` 和 `基底\复刻版6.6山贼 国庆`。独立克隆建议显式传入参数。

## 验收边界

当前 `1.1.0` 为候选源码。离线回归与直接执行生产汇编桥不能替代两版真实游戏的保存、关闭、重启、读取和两页统计逐字段对照。新游戏、同 S 重开、普通读档、正常跨 S 四类事件，以及原生读取带统计扩展块的 E5S，仍须完成实机验收后才能标记发布。

仓库原有 `6.6.11` 发布包的回复量按已验证 HP setter 返回后的正向 HP 变化统计；该构建此前尚未完成实机闭环，伤害、承伤、回复、暴击和连击均应以实际测试结果为准。
