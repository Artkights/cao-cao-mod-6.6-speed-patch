# 曹操传mod6.6 加速补丁

小暗补丁 6.6 的源码归档和单文件 Release 安装器。项目面向 6.6/6.6x 游戏变体，包含加速补丁、阶段加速、超级加速、齿轮模块、简易攻略、战斗统计、安装与卸载逻辑，以及对应的离线测试源码。

## 当前版本

- 版本：`6.6.10`
- 源码目录：[`source/`](source/)
- Release 安装器：[`release/加速补丁6.6安装器.exe`](release/加速补丁6.6安装器.exe)
- 目标平台：Windows x86
- 构建工具：Visual Studio 2022 x86 Native Tools Command Prompt

## 构建

在 `source` 目录中打开 Visual Studio 2022 x86 开发者命令提示符，执行：

```bat
build.cmd
```

运行离线测试：

```bat
build-tests.cmd
```

测试程序只作为源码验证工具保留在仓库中，不属于 Release 交付内容。

## 已知问题

战斗统计中的**治疗量在实机中仍显示为 0**。当前版本虽然包含恢复策略的静态定位、上下文解析和离线桥接测试，但尚未完成实机治疗事件的正确 HP 变化采集，因此不宣称治疗统计已经修复。伤害、承伤、暴击和连击统计的实机状态应以实际测试结果为准。

## 目录说明

- `source/`：源码、资源源文件、构建脚本和测试源码。
- `release/`：面向用户的单文件安装器。

仓库不包含游戏本体、游戏脚本、数据文件、第三方旧补丁 DLL、编译中间文件、日志或测试可执行文件。
