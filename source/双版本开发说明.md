# 加速补丁安装器：6.5 / 6.6

本目录是在原有源码基础上实施的双版本适配。正式发布物只有 `加速补丁安装器.exe`；源码、测试、游戏副本及验收日志均留在开发区域。

## 使用

退出游戏，把安装器放入含 `Ekd5.exe` 的游戏根目录，双击运行。也可以显式指定目录：

```text
加速补丁安装器.exe "游戏根目录" /install
加速补丁安装器.exe "游戏根目录" /uninstall
加速补丁安装器.exe "游戏根目录" /install /quiet
```

无目录参数时使用安装器自身所在目录。命令行选项、返回码及游戏内操作方式沿用原程序。配置仍为原有 74 行加速配置，功能设置单独保存。首次安装保留原始文件备份；升级保留首次备份和用户配置。卸载可通过安装器或游戏菜单发起。

安装器分别保存两套音频代理 DLL，并按引擎调用布局与版本资源选择。支持指定标准 6.5 基底和通过布局校验的兼容 MOD，保留原有 6.6 布局兼容范围。6.5p / 6.5pl 不属于本次兼容承诺。不能唯一识别、版本资源冲突、安装清单冲突时，程序停止安装并说明原因。

## 版本和目录

| 项目 | 6.5 | 6.6 |
| --- | --- | --- |
| 编译宏 | `CCZ_ENGINE65` | `CCZ_ENGINE66` |
| 私有数据根目录 | `patch\xiaoan65` | `patch\xiaoan66` |
| 代理 DLL | 同名 `Koeicda.dll`，6.5 专用载荷 | 同名 `Koeicda.dll`，6.6 专用载荷 |
| 引擎清单字段 | `EngineProfile=65` | `EngineProfile=66` |

清单 `SchemaVersion` 仍为 1。没有 `EngineProfile` 的历史 6.6 清单继续按 6.6 处理；升级时重新校验真实引擎。引擎版本与补丁 `PackageVersion` 分开记录。当前源码构建 `1.1.0` 战场统计修复候选包；发布前须完成下述实机验收。

## 源码结构

- `EngineProfile.*`：磁盘 PE 和运行中映像的版本识别、调用图复核、主程序 SHA-256、统一私有路径。
- `EngineLayout.*` / `Engine.cpp`：两代布局、逐站点模板、原生调用约定、事务写入和恢复。6.5 阶段调用传递 ECX，原生超级加速使用六个站点；6.6 继续使用七个站点。
- `Proxy.cpp`：核心初始化依次启用运行时、统计模型、事务恢复、场景监听和存档监听；早期消息和普通文件调用在加载器回调之外等待就绪。R/S 文件打开只提供资源观察，不驱动统计清零。
- `SaveEnhancer.*`：公共原生保存入口、写入/关闭结果、成功提示前提交、原生读档入口与同步完成恢复；首尾轮换、截图、备注和浏览继续使用原有入口。统计保存不依赖回合自动保存布局全部可用。
- `SaveTransactions.*`：E5S 临时文件、EXS 新鲜度、备份、持久事务日志、失败复原及跨进程读写互斥。6.5/6.6 的普通档、原生自动档、补丁轮换档共用此链路。
- `ScenarioLifecycle.*`：验证实际剧本安装调用链，以原生序号、调用来源和加载事务区分新游戏、新 S 实例、同 S 重装及读档。
- `BattleStats.*` / `BattleRuntime.*`：按版本解析事件来源，以人物编号维护当前战场与全局两个账本；确认的结算直接同时更新，不在战斗结束后重复追加。
- `BattleStatsPersistence.*`：在 E5S 尾部写入 schema 2 统计块，保存两组数据、战场身份、累计时长和覆盖状态，分别校验原生数据与统计内容。兼容读取旧哈希匹配 `.stats`，标记迁移历史不完整。复制或改名 E5S 会携带内嵌统计，游戏所需 EXS 仍须配套。
- `InstallCommon.*` / `Installer.cpp`：版本与安装状态分离、双载荷选择、正式写入前复核主程序指纹、保留备份、失败回滚、清单提交和卸载。

## 构建和复验

需要 Visual Studio 2022 Community 的 x86 C++ 工具链及 Windows SDK。脚本调用 `vcvars32.bat`，使用 C++17、Win32 x86、静态 CRT。支持 Windows PowerShell 5.1 和 PowerShell 7。

```powershell
.\build-dual.ps1 -Tests
.\verify-dual.ps1
```

`build.cmd` 对应普通构建，`build-tests.cmd` 构建两套测试。`build\common` 保存公共 Gear 和卸载助手，`build\65` / `build\66` 保存各代 DLL 与测试，`build\package` 保存最终安装器。`-Publish` 会把安装器复制到中性命名的发布目录，应在回归通过后使用。

验证脚本只读取原始游戏基底，安装事务在新隔离目录中执行。实机安装和运行使用同级验收目录的独立游戏副本。验收记录须区分离线调用图、真实 ABI 执行、安装闭环和实机行为，未实际执行的场景不得记作通过。

1.1.0 发布前还须完成两版真实游戏中的保存、关闭、重启、读取和两页逐字段对照，验证新游戏、同 S 重开、普通读档、正常跨 S 四类事件，以及原生读取带扩展块的 E5S。当前离线测试中的独立写入/读取子进程及直接执行生产汇编桥，不替代上述实机门槛。本轮用户按 Esc 停止游戏 UI 自动操作后未继续实机控制；候选包位于同级 `统计修复-20261022`，正式发布目录未更新。
